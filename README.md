# AV Motors

Статический прототип магазина новых автозапчастей в Одессе. Открывается без сборки: `index.html` и `product.html`. GitHub Pages может обслуживать файлы напрямую.

**Это демонстрация:** цены и наличие не подтверждены, автоматического подбора запчастей, приёма заявок и оплаты нет. Есть бесплатная расшифровка VIN через NHTSA vPIC по явному нажатию кнопки; она не определяет подходящие детали. Черновик заявки можно скопировать. Контакты из заявки не отправляются. При нажатии «Розшифрувати VIN» VIN и выбранный год передаются NHTSA; это объяснено перед кнопкой. Автомобиль и корзина сохраняются только в локальном хранилище браузера; VIN и контактные данные туда не записываются.

## Запуск и проверка

- `python3 -m http.server 8080`, затем открыть `http://localhost:8080`.
- Node.js 22.13+ / 24, `npm ci`, затем `npm test` — 26 регрессионных проверки логики и DOM-сценариев.
- Для ручной проверки: 390 / 768 / 1440px; обе темы; поиск `8973` → сортировка → товар → назад; «Олива» и объём; АКБ и ёмкость; пустая выдача; корзина +/−/удаление; гараж; запрос на отсутствующую деталь; заявка и копирование; Tab / Escape в диалогах.
- JSDOM не проверяет реальную вёрстку или native dialog. Визуальная браузерная проверка этой версии остаётся обязательной перед публикацией.

## Что где настраивать

| Файл | Назначение |
|---|---|
| `assets/js/config.js` | Телефон, график и проверенные ссылки Telegram / Viber / WhatsApp. Пустые контакты не превращаются в неработающие кнопки. Секреты сюда не добавлять. |
| `assets/js/data.js` | Категории и товары. Стабильный числовой id, cat, brand, name, sku, price, type, facet. Необязательное image — путь к реальному фото; oem — массив подтверждённых номеров. |
| `assets/js/catalog-core.js` | Нормализация поиска, единый отбор, параметры, состояние URL, очистка корзины. |
| `assets/js/vin-service.js`, `vin-ui.js` | Бесплатная расшифровка VIN через NHTSA, предупреждение о передаче, частичные ответы, таймаут и ручной резервный путь. |
| `assets/js/shared.js` | Гараж, корзина, черновик заявки, контакты, темы, общие карточки. |
| `assets/js/app.js` | Страница каталога. |
| `assets/js/product.js` | Страница товара, характеристики и возврат к результатам. |
| `assets/css/style.css` | Единые стили обеих тем и адаптивность. |
| `assets/img/logo.svg` | Векторный контур автомобиля и название AV Motors. |
| `docs/PROJECT-PASSPORT.md` | Требования, решения, границы демо, статус проверок и задачи запуска. |

Адрес/название также находятся в HTML: при их изменении обновить обе страницы и паспорт. Настройка `demo` — описание текущего состояния, а не переключатель рабочего магазина.

## SEO и запуск

На страницах задан украинский язык, адаптивный viewport, title и description; у товара title/description уточняются по данным. Ссылки товаров — настоящие `a`, есть заголовки и навигация. Прототип имеет `noindex,follow`, чтобы не индексировать неподтверждённые цены. Не блокировать его в robots.txt, иначе поисковик не увидит noindex.

Для запуска подготовить настоящие отдельные страницы категорий/товаров (желательно статическая генерация или серверный рендеринг), уникальные описания, canonical и sitemap по финальному домену. Product/Offer и LocalBusiness добавлять только с подтверждёнными данными, не с демо-ценами или выдуманными отзывами. Правила индексации фасетных URL нужно настроить отдельно.

GitHub Pages не принимает серверные заказы сам по себе. Для заявок нужен серверный обработчик или согласованный сервис; для учёта — выбранная система или отдельная админ-панель с авторизацией. Публикация сайта не заменяет подключение этих функций.

## Публикация изменений

Обновления опубликованы в main и GitHub Pages с разрешения пользователя. Ресурсы имеют номер версии для согласованного обновления кеша. Для проверки адаптивной вёрстки доступна qa/responsive.html (320/390/768px, noindex). Эта проверка в Chromium не заменяет реальный iPhone/Safari.

## Источники данных и изображений

Четыре позиции получили изображения и отдельные характеристики из официальных каталогов производителей. Источники и статус прав записаны в `docs/IMAGE-SOURCES.json`. Доступность фото в интернете не подтверждает лицензию на коммерческое воспроизведение. Перед публичным запуском согласовать права или заменить фото своими/лицензированными. Остальные 24 позиции ещё с иллюстрациями; весь ассортимент пока демонстрационный.

Обзор VIN, API каталогов и ограничений: `docs/DATA-INTEGRATIONS.md`.
