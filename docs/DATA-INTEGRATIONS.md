# VIN, каталог и фотографии: что подключено и что требуется

Проверено 12 сентября 2026.

## Бесплатная идентификация VIN

NHTSA vPIC — открытый API без регистрации приложения и платного ключа. База опирается на данные производителей о машинах для американского рынка; полнота для европейских модификаций не гарантирована. VIN-декодер сообщает данные автомобиля, а не список подходящих деталей, историю аварий или пробег.

- Документация: https://vpic.nhtsa.dot.gov/api/
- FAQ и условия бесплатного использования: https://vpic.nhtsa.dot.gov/api/Home/Index/FAQ
- Выгрузка собственной базы предлагается в документации API. Это база VIN, а не база запчастей.

В код добавлены `vin-service.js` и `vin-ui.js`: формат VIN → явно инициированный запрос → обработка неполного/ошибочного ответа → отдельная подстановка в форму. Изменение VIN и закрытие формы отменяют запрос. VIN не сохраняется в localStorage. При недоступности API ручной ввод остаётся рабочим. HTTP и CORS проверены на частичном VIN из официального примера; реальный пользовательский VIN для тестов не использовался.

## Применимость и автомобильный каталог

Для точного подбора нужна **база применимости** (fitment) и каталог деталей. Библиотека UI для фильтров не содержит этой информации. TecDoc Web Service предоставляет API для данных автомобилей, товаров, связей, изображений и технических критериев. Это лицензируемый продукт; пробный доступ к веб-каталогу не означает права встроить данные в свой магазин.

- API-продукт: https://www.tecalliance.net/products/cards/tecdoc-web-service
- Каталог: https://www.tecalliance.net/products/cards/tecdoc-catalogue
- Условия использования и источники лицензированных данных: https://www.tecalliance.net/our-customer-contracts-faqs

Не подключать найденную в сети «бесплатную базу TecDoc» с непонятным происхождением. Условия хранения, обновления, использования изображений и кросс-номеров зависят от договора. На этой итерации платный сервис не заказан, ключи не запрашивались, база применимости не импортирована.

## Как наполнить магазин без фотографий поставщика

1. Зафиксировать точный бренд, артикул и фасовку. В исходном демо есть условные SKU вроде KYB-EXG — для них нельзя гарантированно подобрать фото реального артикула.
2. Найти официальный каталог производителя / медиацентр / лицензированный источник. Конкурентов использовать для сверки, не как автоматическое подтверждение прав на фото.
3. Сопоставить номер и вариант, сохранить URL источника, дату и статус прав. Проверить, что изображена нужная деталь, а не похожая модель или упаковка другой фасовки.
4. Подключить файл через `image`, официальную страницу через `source`, подтверждённые характеристики через `specifications` и `approvals`.
5. До публичного коммерческого запуска подтвердить разрешение на использование или заменить фото собственным. Цены и остатки получить от продавца отдельно.

Сейчас привязаны 4 точные позиции. Каталоги:

- MANN-FILTER HU 7019 z: https://www.mann-filter.com/ua-uk/catalog/search-results/product.html/hu7019z_mann-filter.html
- Brembo P 85 020: https://www.bremboparts.com/europe/en/catalogue/pad/P_85_020?compatibility=true
- Brembo 09.A200.11: https://www.bremboparts.com/europe/en/catalogue/disc/09-A200-11

Полного наполнения реальными фотографиями пока нет. Реестр исходных изображений — `IMAGE-SOURCES.json`. Механизм допускает поэтапное добавление остальных фотографий без перестройки сайта.
